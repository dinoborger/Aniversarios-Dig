# Aniversários Pro
PWA Android sem servidor. Dados em localStorage do navegador, com exportação/importação JSON. Não inclui PostgreSQL nem agendamento garantido de notificações em segundo plano.

## Publicar pelo Android
1. Criar um repositório público no GitHub.
2. Enviar os ficheiros desta pasta para a raiz do repositório (não enviar apenas o ZIP).
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Abrir o endereço HTTPS indicado no GitHub Pages no Chrome Android.
5. Menu ⋮ > Instalar aplicação ou Adicionar ao ecrã principal.

## Segurança
Os dados são armazenados apenas no perfil do navegador e podem desaparecer ao limpar dados do site. Não guardar informação sensível nas notas. Fazer backups JSON.
